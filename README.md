# Ditto Docs

Documentation and marketing site for [Ditto](https://ditto.pub), a fun and customizable Nostr client made by [Soapbox](https://soapbox.pub).

Built with [VitePress](https://vitepress.dev/).

## Development

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
bun run preview
```
